# Colonnes (communes à Dataset 1 et Dataset 2)

| Colonne | Feature / Target | Description |
|---|---|---|
| `surface_m2` | Feature | Surface habitable de la maison, en mètres carrés. |
| `nb_pieces` | Feature | Nombre de pièces de la maison. |
| `age_annees` | Feature | Âge de la maison, en années. |
| `distance_centre_km` | Feature | Distance entre la maison et le centre-ville, en kilomètres. |
| `price` | Target | Prix de vente de la maison, en euros — variable à prédire. |
